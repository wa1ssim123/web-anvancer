HORENOVA · APPLICATION WEB

Votre univers.
Toujours à portée.

Ajoutez HORENOVA à l'écran d'accueil de votre téléphone ou de votre ordinateur pour l'ouvrir comme une application, sans télécharger de fichier ni payer d'abonnement.

01 · iPhone et iPad

Depuis Safari

1. Ouvrez horenova.com dans Safari.
2. Appuyez sur Partager.
3. Choisissez Sur l'écran d'accueil puis ajoutez HORENOVA.

02 · Android

Depuis Chrome

1. Ouvrez horenova.com dans Chrome.
2. Ouvrez le menu ⋮ du navigateur.
3. Sélectionnez Installer l'application ou Ajouter à l'écran d'accueil.

03 · Windows

Depuis Edge ou Chrome

1. Ouvrez horenova.com dans votre navigateur.
2. Dans le menu, cherchez Applications / Installer ce site ou Installer HORENOVA.
3. Confirmez l'installation pour ouvrir HORENOVA depuis le bureau.

Cette installation ajoute une application web (PWA). Elle ne correspond pas à une publication sur Apple App Store ou Google Play. Certaines fonctionnalités nécessitent une connexion Internet et un compte HORENOVA.
